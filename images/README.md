# Images Directory

This directory contains all images used in Module 4: Quality Control and Quality Assurance.

## Image Categories

### Quality Control Diagrams
- Trend analysis charts (Levy-Jennings plots)
- Control monitoring examples
- Westgard rules visualization

### Case Study Images
- Laboratory workflow diagrams
- Sample labeling examples
- Contamination scenarios

### Reference Materials
- PCR controls examples
- Proficiency testing panels

## Image Guidelines

- **Format**: Prefer PNG for diagrams, JPG for photographs
- **Resolution**: Minimum 1200px width for main images
- **Naming**: Use descriptive names (e.g., `levey_jennings_plot.png`)
- **Alt Text**: Provide descriptive alt text for accessibility
